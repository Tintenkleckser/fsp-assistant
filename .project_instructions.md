# FSP-Assistent Project Instructions

## Overview
FSP (Fachsprachenprüfung) Vorbereitungs-App für ausländische Ärzte. Bildet die 3 Prüfungsteile ab: Anamnese (Arzt-Patient), Dokumentation (Kurz + Ausführlich), Übergabe (Arzt-Arzt). Fokus: Sprachkompetenz im klinischen Alltag.

## FSP-Prüfungsstruktur
Die App bildet die **drei Teile** der Fachsprachenprüfung ab:
1. **Teil 1: Arzt-Patienten-Gespräch (Anamnese)** – Verstehen & Sprechen in Laiensprache (20 Min)
2. **Teil 2: Dokumentation** – Schnelle Kurzdoku (Halbsätze) + ausführlicher Aufnahmebericht (ganze Sätze) (20 Min)
3. **Teil 3: Arzt-Arzt-Gespräch (Übergabe)** – Fallvorstellung in Fachsprache (20 Min)

**Kernprinzip:** Es geht um **SPRACHKOMPETENZ**, nicht um medizinisches Fachwissen. Typische Szenarien: Notaufnahme, stationäre Aufnahme.
- Keine medizinischen Fachgebiete als Auswahl
- SIMULATION_TYPES hat nur 3 Einträge: `patient_conversation`, `documentation`, `doctor_conversation`
- TOPIC_CATEGORIES wurde entfernt
- Der "Neue Übung"-Wizard hat nur 2 Schritte: Prüfungsteil → Schwierigkeitsgrad

## LLM API
- **Provider**: Mistral AI (api.mistral.ai)
- **Model**: mistral-large-latest
- **API Key**: MISTRAL_API_KEY (env variable)
- All 3 API routes (generate, evaluate, stream) use Mistral's OpenAI-compatible endpoint

## Technical Stack
- Next.js 14 (App Router), TypeScript, Tailwind CSS, Prisma ORM
- Auth: Supabase Auth (NOT NextAuth) — no `/api/auth/providers` endpoint
- DB: Abacus AI hosted Postgres (`DATABASE_URL`), Supabase pooler (`DIRECT_URL`)
- LLM: Abacus AI API for simulation generation/evaluation/streaming

## Design & Style
- Medical/professional theme with blue/teal accent colors
- Bilingual: German (primary) + Turkish
- i18n via `lib/i18n.ts` with `useTranslation()` hook
- "Übung" (practice) terminology, NOT "Prüfung" (exam) for buttons

## Key Architecture
- `lib/topic-categories.ts`: SIMULATION_TYPES with timeLimitMin per type, getTimeLimitForType() helper
- `chat-client.tsx`: Main simulation chat with countdown timer (MM:SS), warning at ≤5min (amber), critical at ≤1min (red pulse), auto-end at 0
- `fsp_progress` table tracks user progress per simulation type
- Evaluation auto-saves to fsp_progress after completion
- Prisma uses `@@map` for snake_case DB tables, camelCase in code
